# Third-party components and licences

Rule: nothing is added to the app, the engine or the package without a row here (licence checked at the source, version, how it is bundled). Binaries carry a SHA-256. Licence texts are copied to `resources/licenses/` when the component is bundled (from M2).

Status: **in use** = in `package.json` / the repo today; **planned** = chosen in `docs/PLAN.md`, added by the milestone shown.

## Notices that travel with every exported ROM (W0 P1-4)

Every ROM Blum exports contains compiled nesdoug.lib (MIT: the notice must accompany copies), neslib (public domain) and the FamiStudio sound engine. So:
- the cartridge sheet has a « Composants » section with these notices (tested in M5-T4);
- the ROM's ending is followed by a short credits screen naming them (PLAN §5.9).

## Package notices (W0 P2-5, P2-10)

- Electron's `LICENSE` and `LICENSES.chromium.html` (Chromium, ffmpeg) stay in the package; M5-T6 asserts them.
- Press Start 2P and Pixelify Sans are shipped as subset woff2 files, which is fine under OFL-1.1; the OFL texts go in `resources/licenses/`.

## Explicit no

- Nova the Squirrel code or assets (GPL code; assets CC BY-NC-SA with character use forbidden).
- NESmaker / Retro Game Forge (proprietary).
- FamiTracker NSF driver (unlicensed), FamiTracker / 0CC / Dn-FamiTracker binaries (GPL, not needed).
- I-CHR, NEXXT binaries (no clear licence).
- Repos without a licence file (e.g. kmck/nesify).
- ditherjs (CC-BY-SA on code).
- Any commercial ROM, any Nintendo asset, logo, font or character. The ROM font is drawn by us, never traced from a commercial game font (W0 P2-3).
- NES/SNES cartridge silhouettes or label layouts in the UI (trade dress, W0 P2-4).
- Reading NesTiler source while writing the converter (GPL-3 contamination of the giftable app).
- Bundling Mesen in the package (GPL-3 §6 source obligation).
- keytar (archived).
