NES BLUM FACTORY

Ton studio pour fabriquer de vrais jeux NES, avec cinq directeurs qui proposent et toi qui approuves. Une page pour bien partir.

1. Installer (une seule fois)

  1. Avant d’extraire : clic droit sur NES-BLUM-FACTORY-1.3.0-win-x64.zip, Propriétés, coche « Débloquer » en bas, puis OK. Sans ça, Windows peut bloquer le compilateur caché dans le dossier.
  2. Clic droit sur le zip, Extraire tout…, par exemple dans Documents.
  3. Ouvre le dossier NES BLUM FACTORY et double-clique sur NES BLUM FACTORY.exe. Rien d’autre à installer.
  4. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires, puis Exécuter quand même. L’app n’est pas signée : c’est un cadeau fait maison.
  5. Si Windows parle de « Smart App Control » (PC neuf, pas de bouton « Exécuter quand même ») : Sécurité Windows, Contrôle des applications et du navigateur, Smart App Control, mets Désactivé. Attention : selon la version de Windows, on ne peut plus le rallumer sans réinstaller Windows. Si tu préfères le garder, demande à Fred.

2. Ta clé Claude (sur ton PC à toi)

  1. Crée une clé API sur console.anthropic.com (menu API Keys). Garde-la pour toi. Ajoute un peu de crédit prépayé dans Billing (5 $ suffisent pour beaucoup de discussions).
  2. Dans l’app : Réglages, colle la clé, Enregistrer, puis Tester.
  3. Windows la chiffre sur ce PC, pour ton compte. Elle n’est jamais affichée ni écrite dans un fichier lisible. Sur un autre PC, il faut la retaper.
  4. Chaque réponse d’un directeur affiche son coût estimé ; tu peux fixer un plafond par mois dans Réglages.

Sans clé, tout marche quand même : modèles d’histoire, réglages de saut, éditeurs, construction de la ROM, jeu et export.

3. Premiers pas

  • Écran titre : Entrée. Puis « Ta première cartouche » : cinq étapes, une par directeur, de l’histoire jusqu’à la ROM.
  • Ou ouvre « Jeu d’exemple BLUM » : une copie du jeu fait pour toi. Tu peux tout changer et relire son historique.
  • Jouer : flèches pour bouger, X pour sauter (deux fois de suite pour le double saut), Z pour lancer de la tire, Entrée pour Start. Une manette marche aussi.
  • Partie perdue ? Start pour continuer au début du monde, avec 3 vies (Maj, c’est Select : retour au titre).

SEBRING, la course

Ton deuxième jeu : en décapotable, de Ville d’Anjou au centre-ville en 5 étapes (Anjou, Métropolitaine, Sherbrooke Est, Plateau, centre-ville). Écran des cartouches : « Jeu d’exemple SEBRING ». Flèches pour tourner, X (A) pour accélérer, Z (B) pour freiner, Entrée (Start) pour la pause, Maj (Select) pour changer de poste de radio. Les points de contrôle ajoutent du temps ; temps écoulé, Start pour continuer (3 fois). La ROM et sa fiche sont dans Jeu SEBRING.

THE LEGEND OF BLUM, le début

Ton troisième jeu, le début d’un jeu de rôle : le prologue chez Madame Bélanger, puis la maternelle et la 1re année à l’école Chénier. Écran des cartouches : « Jeu d’exemple THE LEGEND OF BLUM (début) ». Flèches pour marcher, X (A) pour parler et valider, Z (B) pour le texte plus vite et pour annuler, Entrée (Start) pour le menu. Cinq classes : Guerrier (frappe fort), Mage (touche tous les ennemis), Voleur (vole une collation), Archer (ignore la défense), Nécromancien (un allié pendant 2 tours). La partie se sauvegarde dans l’app : « Continuer » sur l’écran titre. La ROM et sa fiche sont dans Jeu THE LEGEND OF BLUM. À SUIVRE.

4. Sur une vraie cartouche

Dans BOULON, Exporter écrit le jeu et une fiche cartouche (page HTML avec tous les chiffres et les sommes de contrôle).

  • Cartouche flash (type EverDrive) : copie le fichier .nes sur la carte SD.
  • Programmateur de puces (type T48 ou TL866) : -PRG.bin (256 Ko) dans la puce du programme, -CHR.bin (128 Ko) dans la puce des graphismes.

La carte doit avoir 8 Ko de RAM de travail (PRG-RAM) : carte MMC3, mapper 4, de type TKROM ou TSROM. Sans cette RAM, le jeu plante au démarrage. Les cartouches flash l’ont déjà.

Pour vérifier une ROM avant de la graver, l’émulateur gratuit Mesen (www.mesen.ca) est très précis.

5. Si quelque chose coince

  • Tout est dans Aide, dans l’app.
  • Tes jeux sont dans Documents\NES BLUM FACTORY, un dossier par jeu. Exporter (zip) en fait une copie de sauvegarde.
  • Chaque changement s’annule dans Historique.
